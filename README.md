# Traffic history for cboone/agent-harness-plugins

Generated daily by the Traffic history workflow, using `bin/record-traffic` from the default branch. Do not edit this file by hand.

GitHub keeps traffic data for 14 days. This branch keeps it indefinitely: `daily.json` holds clones and views per UTC day, and `snapshots/` holds GitHub's popular referrers and paths, each a 14-day total, as fetched on each date.

## Reading the clone counts

- **CI checkouts** are the `actions/checkout` steps that ran in this repository's Actions runs created that day, across every job and attempt. Checkout steps given a custom name are not recognized.
- **Dynamic jobs** are the jobs of GitHub-managed runs with the `dynamic` event, such as Copilot pull request reviews and Dependabot updates, which clone the repository without a checkout step.
- **Est. external clones** are clones minus both, floored at zero. They still include marketplace update fetches from existing installs, the maintainer's own machines, and any automation the counts miss, such as this workflow's own fetch of this branch.
- Unique cloner counts cannot be adjusted the same way, so they are shown as GitHub reports them.
- `n/a` marks a figure that is not available. In the clone and view columns, GitHub reported nothing for that day. In the automation and estimate columns, the day has not been counted: it is the current day, it still had Actions runs in progress, or it left GitHub's 14-day window before a run counted it.
