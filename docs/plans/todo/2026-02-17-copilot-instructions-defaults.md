# Add Copilot Instructions Defaults to Scaffold and Agent Config Skills

## Context

Analyzed copilot-instructions.md files across 13 original (non-fork) repos in `~/Development`. Found strong commonalities in structure and content that should inform the defaults generated by the scaffold-new-repo skill and the guidance provided by the clean-up-agent-config skill.

Key findings:
- All 13 files have a PR Review section as the primary content
- All 13 use bold-key "do not flag" items documenting intentional design decisions
- 4 use the "pointer" pattern (cross-ref to AGENTS.md + Copilot-specific rules) — this is the newer, preferred approach
- 8 of 13 include a `<!-- KEEP THIS FILE UNDER 4000 CHARS -->` HTML comment, but this limit is **not documented by GitHub** — it was cargo-culted from an unrelated Microsoft Copilot (Bing/Edge) input limit. The actual GitHub guidance is simply "keep concise, put critical rules first."
