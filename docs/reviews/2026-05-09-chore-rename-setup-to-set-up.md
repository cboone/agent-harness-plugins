## Summary

This branch performs a breaking rename of four plugins from the `setup-*` prefix to `set-up-*` (`setup-ci` → `set-up-ci`, `setup-installers` → `set-up-installers`, `setup-linters` → `set-up-linters`, `setup-secret-scanning` → `set-up-secret-scanning`), bumps each renamed plugin's major version, recomputes the marketplace catalog state, and propagates the new names through every cross-reference in plugin manifests, READMEs, sibling skills, the root README catalog, and the regenerated Codex and OpenCode mirrors. It also corrects a stale skills-vs-commands distinction in the bootstrap-project skill that no longer matched current plugin layout.

### Potential Issues

- **Stale `"setup"` keyword in `plugins/set-up-linters/.claude-plugin/plugin.json`**: the `keywords` array still contains `"setup"`. This is plausibly intentional (legacy discoverability) but inconsistent with the new naming. The other three renamed plugins did not have a literal `"setup"` keyword to begin with. Consider either dropping it or replacing it with `"set-up"` for consistency, but it does not affect functionality.
- **Cosmetic table-alignment drift in `bootstrap-project` SKILL**: the example execution table in `plugins/bootstrap-project/skills/bootstrap-project/SKILL.md` keeps the original column padding even though `set-up-*` is one character longer than `setup-*`, so the second column now has an extra space on those rows. Markdown tables still render correctly (column alignment is delimiter-based), so this is purely visual drift in the source.
- **No backwards-compatibility shim**: as expected for a `feat!:` rename, there is no alias plugin or redirect for the old `setup-*` slash commands. This is the right call (CLAUDE.md explicitly discourages backwards-compatibility hacks), but it is worth flagging in the PR description so users can plan the reinstall.
- **Codex/OpenCode parity**: the codex mirror tracks the rename one-for-one. The OpenCode mirror only carries skill symlinks (the rename is reflected by deleting `setup-*` and adding `set-up-*` symlinks), and `bin/build-opencode-mirror` reports `skills: 51, commands: 0, plugins: 2`, matching the expected post-rename state.
