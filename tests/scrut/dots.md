# Dots skill contract

These source-contract checks complement the live renderer measurement in the dots plan. They do not predict model compliance.

## Canonical invocation policy and response contract

```scrut
$ cat "${REPO_ROOT}/plugins/dots/skills/dots/SKILL.md"
---
name: dots
description: Print 50 dot lines. Use only when explicitly invoking dots to scroll the conversation off screen.
disable-model-invocation: true
---

# Dots

## Workflow

1. Reply with exactly one code block containing 50 lines, each a single `.`. Output nothing else: no surrounding text and no tool calls.
```
